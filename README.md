# Fiesta SMP Official Website

Official website for **Fiesta SMP** — a long-haul survival Minecraft server with pure physical barter, raiding, long-term seasons, and full crossplay for Java Edition and Bedrock Edition.

Styled with an authentic **Microsoft in 2009 / Windows 7 Aero UI & UX** (glossy aero glass gradients, Segoe UI typography, signature 4-column feature grid, "Get Windows 7 Today" showcase, and chevron bullet navigation).

## 🌐 Live Pages

- **[Home](https://open-fiestasmp.github.io/)** (`index.html`) — Microsoft 2009 styled showcase, server compatibility matrix, core specifications, 4-column feature spotlights, quick join walkthrough, and destination directory.
- **[News & Updates](https://open-fiestasmp.github.io/news.html)** (`news.html`) — Official announcements, season roadmaps, gateway firmware updates, Saturday stream recaps, and category filtering.
- **[Terms & Rules](https://open-fiestasmp.github.io/terms.html)** (`terms.html`) — Windows 7 Explorer 2-pane policy layout: allowed vs. prohibited mechanics, barter economy charter, and administration notice.
- **[Gallery](https://open-fiestasmp.github.io/gallery.html)** (`gallery.html`) — Community postcards and screenshots with an authentic Windows Photo Viewer aero lightbox dialog.
- **[Socials](https://open-fiestasmp.github.io/socials.html)** (`socials.html`) — Broadcast channels (Twitch, Kick, YouTube), comms (Discord, X, Mail), and Google Calendar embedder.
- **[Contact & Support](https://open-fiestasmp.github.io/support.html)** (`support.html`) — Official communication email, Google ban appeal form, report tickets, and FAQ accordion.
